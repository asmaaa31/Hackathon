This project is an educational game, built in GameMaker, that teaches how two classic search algorithms, breadth-first search (BFS) and depth-first search (DFS), find their way through a maze. 
Each round generates a new random maze with a random start and goal, and the player has to predict which algorithm will reach the goal after exploring fewer cells by typing "bfs" or "dfs".
The game then runs both searches on the same maze, stepping through them one move at a time with a plain-English explanation of every step, 
such as which neighbours were checked and what is waiting in the queue or stack. 
Players can go back a step, switch to autoplay, and use on-screen buttons, and the result screen reveals the answer and keeps score.
A separate sandbox mode lets them draw their own walls and run either algorithm to see how they behave.
